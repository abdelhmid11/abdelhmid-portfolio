# Abdelhamid Ibrahim — Portfolio

A premium, responsive personal Software Engineer portfolio built with React and Vite.

## Run locally
```bash
npm install
npm run dev
```

## Customize
- Personal information and editable placeholders: `src/data/profile.js`
- Projects: `src/data/projects.js`
- Skills, experience, and education: `src/data/skills.js` and `src/data/experience.js`
- Replace the portrait placeholder at `public/images/profile.svg` (or update `profileImage` to `/images/profile.jpg` after adding your photo).
- Project visuals live in `public/images/projects/` and are currently polished local SVG placeholders.

The contact form is intentionally frontend-only and validates fields without pretending to send data.
